# Test plan

1. 数据基础：验证 Pydantic Schema、列表扫描、UTF-8 JSON / Markdown、真实 PDF 页数和校验值，读写不存在/损坏数据的错误状态。
2. 导入：arXiv URL/ID 和历史 ID 解析，固定精确版本，缺失源文件降级，重复导入不替换现有版本，本地 PDF 上传、扫描/加密限制，源码路径穿越/链接过滤与解压限制。
3. 持久化：新服务实例重新读取笔记，etag 旧窗口冲突，写入失败保留旧值，纠错追加、撤回与重生成冲突处理，发布中断回滚。
4. 来源：verified 引句与页文本匹配，伪造引句/错误页码/错误版本拒绝发布，Markdown 与 JSON 同源，页码采用 1 基。
5. 本地安全：Host / Origin / fetch-site，固定资源路径，遍历与符号链接检查，PDF.js worker MIME，安全 Markdown / KaTeX，依赖审计。
6. 真实浏览器（`scripts/prepare_e2e.py` 在 tmp/ 隔离目录生成演示论文与报告，不读取用户论文；设置 `PAPERLAB_E2E_ARXIV=<arXiv ID>/<版本>` 可额外运行 RAP 源码用例）：原文 canvas / text layer，六个报告标签与公式，点击引用跳页/高亮，未匹配降级、目录/缩放/分栏、阅读位置、选文/剪贴板、笔记/纠错刷新、真实报告再次生成后的人工数据保留、本地 PDF 导入、错误恢复与普通笔记本视口。
7. Windows 运维：安装锁文件可用、启动健康检查、停止只结束本项目服务、重新启动后笔记保持、Git 忽略 PDF/缓存和敏感配置。

测试数据放在 tmp/ 的隔离目录。浏览器不操作真实 ChatGPT；只检查提示上下文和链接，用户自行发送问题。
