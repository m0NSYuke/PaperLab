# PaperLab Research 网页工作台

本机入口：http://127.0.0.1:8000/ 。继续使用原有 ChatGPT 登录与 Codex 订阅额度，无需增加模型 API Key。

## 四个入口

- **读论文**：导入 arXiv / 本地 PDF，查看现有讲解、原文、中英对照、Study、笔记和待追问问题。阅读器中可把固定版本带入深度解读或写作台。
- **写作台**：选择任务，填写要求和真实材料，可关联最多三篇固定版本论文；X-Ray 每次一篇。写作与润色可选择章节、语言和目标期刊。
- **研究工具**：22 项 Nature Skills 可搜索并按阅读、写作、文献研究、图表汇报、审稿研究计划分类筛选。每张卡明确执行方式。
- **成果库**：查看任务状态，重新打开草稿或任务包。任务地址包含 ID，刷新不会丢失正在运行的任务。

## 哪些任务直接执行

网页可直接生成七类文字草稿：讲透一篇论文、起草论文章节、学术润色与翻译、检查统计表述、数据与代码声明、文字实验记录、社科研究问题梳理。

每次读取实际安装且哈希匹配的技能及相关资源，再通过已有受限 Codex 运行器输出结构化结果。草稿不是正式论文报告，不替代研究判断。文献原生文本可以输入，但网页运行器不联网检索、不运行上游脚本、也不查看页面图像。公式、图表和扫描页需对照原文。

其余十五项需要完整工具环境：双语 reader、精读卡、版式中文 PDF、学术检索、Nature/CNS 支撑引文、参考文献核查、全文下载、文献流水线、科研图、论文 PPT、图片转 PPT、模拟审稿、审稿回复、研究计划与专利草稿。

这些任务先生成本地 `task.md` 和包含请求、版本、PDF 哈希、页文本的 `source-material.json`。页面状态是 **任务包待执行**，并提供「复制给 Codex 执行」。把这条指令交给以 PaperLab 为工作目录的 Codex，即可进入原技能完整流程。网页不会把材料准备误报为文件制作或联网核查成功。机构账号、可选服务或额外模型尚未配置的，按具体任务处理；没有批量启用付费服务。

在 `.env.local` 的 `PAPERLAB_GPT_AUTHORED` 中列出的论文保持由 GPT 撰写分析：网页会提示继续在原 GPT 会话补充，并阻止 Codex 重写。

## 保存与核验

- 新成果保存在 `research-outputs/job_<ID>/`。已生成草稿有 `draft.md`、包含模型回执和原始输出的 `result.json`；人工修改前的版本在 `.history/`。
- 修改后点「保存修改」再下载。过期窗口不能覆盖较新版本；切换页面与关闭窗口前会保护未保存修改。
- 关联 PDF 固定哈希，生成前后均检查。返回引句逐项与指定页文本匹配；这证明文字存在，仍需审阅它是否支持当前结论。
- 已生成任务的原始技能版本与来源保存在 `.runtime/jobs/<ID>/`。备份时一并保留 `research-outputs/` 和既有 papers、local-assets 等数据目录。
- 原始 PDF、人工 notes/study/questions/qa/corrections、翻译和概念库不由这些任务重写。现有报告仍经原发布器校验。

## 建议验收

1. 打开研究工具，搜索「润色」，进入后粘贴一段真实草稿、写明要求并生成。
2. 编辑成果并保存，刷新后从成果库打开，下载 Markdown 对照。
3. 从论文阅读器选择「深度解读」，固定该论文版本，要求设计动机、公式教学例子和常见疑问。原文引句可展开核对。
4. 选择论文汇报 PPT，关联论文、准备任务包，检查状态和任务说明，再复制给 Codex 执行完整制稿流程。

真实执行过的检查见 [TEST_RESULTS.md（本地记录，不随仓库发布）](TEST_RESULTS.md（本地记录，不随仓库发布）)。安装完整性与第三方许可见 [NATURE_SKILLS.md](NATURE_SKILLS.md)。
